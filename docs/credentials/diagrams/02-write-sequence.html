A Tower write, end to end

Re-run on a PipelineRun, from the click to the new run. The write token exists for this one action: minted after the ownership check, used twice, never stored.

Before any token

The backend refuses a user who doesn't own the app (tower.pipeline.rerun, or .cancel), and records the refusal. No token is minted for a refused request.

The token

TokenRequest for backstage/tower-actor: audience kiac-dev, 600 s. Backstage's ServiceAccount may create tokens for that one name only.

At kiac-dev

The token must come from kind-prod's issuer, carry audience kiac-dev, name backstage/tower-actor and live at most 600 s. tower-pipelinerun-shape then allows only Glidepath's own run shape in an app's -cicd namespace.
