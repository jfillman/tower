# Tower brand

The Hangar **Instrument Dial** (ring, eight ticks, heading bug at 12 o'clock) with Tower's glyph in the centre: a mast
with signal arcs. **Amber**, the Hangar colour for the products that need attention.

| File | Use |
|---|---|
| `tower-tile.svg` | Fixed instrument-black rounded square. README headers, catalog tiles, avatars. |
| `tower-social-preview.png` | 2560 x 1280 social preview. **Upload by hand** in Settings, General, Social preview: GitHub has no API for it. |

The full set of marks for every Hangar product, the family rules and the palette are in `../../brand/README.md` (a copy
of Hangar's) and in the Hangar Brand System, https://github.com/jfillman/hangar/tree/main/docs/brand.
